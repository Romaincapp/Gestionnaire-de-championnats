⚠️ Peut exclure certains joueurs selon la stratégie choisie

Choisissez comment répartir les joueurs dans les divisions

🎯 Par Niveau

Les joueurs restent dans leur division, triés du meilleur au moins bon
Usage : Simple pré-remplissage, sans changement de division

🐍 Serpent (Snake Draft)

Dans chaque division : 1er, dernier, 2e, avant-dernier, 3e... (mélange forts/faibles)
Usage : Équilibrer les poules, éviter que les meilleurs soient ensemble

⚖️ Mixte Équilibré

Dans chaque division : alternance 1 fort, 1 moyen, 1 faible (répartition équitable)
Usage : Poules très équilibrées, matchs variés, tournoi convivial

🔄 Équilibrer les Divisions

Promotions/Relégations : Les meilleurs de chaque division montent, les derniers descendent
Usage : Maintenir des divisions équilibrées tout au long du championnat
